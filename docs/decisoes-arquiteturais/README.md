# Decisões arquiteturais

Os ADRs registram contexto, decisão, alternativas e consequências. Uma decisão
aceita só deve ser substituída por outro ADR que explique a mudança.

| ADR | Decisão | Status |
| --- | --- | --- |
| [0001](0001-nestjs-typescript-monolito-modular.md) | NestJS, TypeScript estrito e monólito modular | Aceito |
| [0002](0002-persistencia-mongodb-repositorios.md) | MongoDB/Mongoose, repositórios e índices explícitos | Aceito |
| [0003](0003-compatibilidade-api-criptografia.md) | Preservação da API e criptografia explícita | Aceito |
| [0004](0004-validacao-configuracao-seguranca.md) | Validação, configuração e segurança nas fronteiras | Aceito |
| [0005](0005-qualidade-testes-implantacao.md) | Build ESM, testes e implantação | Aceito |

Para adicionar uma decisão, use o próximo número e registre: data, status,
contexto, decisão, alternativas, consequências e critérios de revisão.
